# Kanban

[Kanban](https://wikipedia.org/wiki/kanban_(development)) is a simple scheduling system in project management, originally used in [lean-six-sigma](lean-six-sigma.md) methodology.

## Kanban Board

One of the principle and famous tool used is the [Kanban board](https://en.wikipedia.org/wiki/Kanban_board)

Tasks (e.g [User Story](agile.md#User%20Story)) are written on cards that are placed in columns on a [board](https://wikipedia.org/wiki/kanban_board), which represent its current status. The columns are typically labelled according to the advancement of the task.

**Example**

| Backlog / TODO   | Pending / In Progress | Review | Done                       |
| ---------------- | --------------------- | ------ | -------------------------- |
| Task F<br>Task G | Task E                | Task D | Task A<br>Task B<br>Task C |
